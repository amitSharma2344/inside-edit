# Reel Insights Template Editor

A mobile-first, local-only editor for a fixed 390 × 844 demo analytics template. Editable text, metrics, audience bars, graph data, and the Reel thumbnail are separated from locked visual styling. No platform login or live analytics are used.

## Run

```sh
npm install
npm run dev
```

Projects are stored in this browser's local storage. Export supports PNG and JPG for the active screen or all three primary screens.
